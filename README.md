SmartBilling 🛒

SmartBilling is a full-stack Grocery Store Management System built to manage the main day-to-day operations of a grocery store from one centralized platform.

🚀 Features
🔐 Admin Authentication – Secure login and administrator access.
📦 Inventory Management – Manage products, categories, suppliers, stock levels, stock alerts, and stock audits.
🧾 Billing & Sales – Create bills, manage billing records, payments, and sales information.
🔄 Returns & Refunds – Manage product returns and applicable refunds.
👥 Customer Management – Maintain customer information and purchase records.
📊 Reports & Analytics – Analyze sales, product performance, customer activity, and financial data.
⚙️ Settings – Manage store and application settings.
🌙 Light & Dark Theme – Switch between professional light and dark interfaces.
🛠️ Technology Stack
Layer	Technology
Frontend	HTML, CSS, JavaScript
Backend	Python, Flask
Database	MySQL
ORM	SQLAlchemy
🔄 System Architecture
HTML + CSS + JavaScript
          ↓
     Python Flask
          ↓
        MySQL

The frontend communicates with the Flask backend, which handles application logic, validation, authentication, and database operations.

🎯 Project Goal

The main goal of SmartBilling is to provide a centralized system for managing inventory, billing, customers, suppliers, returns, and business reports, while reducing manual work and keeping store data organized.

📌 Project Type

Full-Stack Web Application

🔐 Authentication

The current system uses Admin Authentication. Manager and Staff/Cashier accounts are not part of the current implementation.
